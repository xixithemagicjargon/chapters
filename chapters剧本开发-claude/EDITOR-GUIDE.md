# Chapters 审核插件 — 编辑使用说明

当前版本：`0.44.0`

## 一、安装

1. 收到 `chapters-plugin-x.y.z.zip`，**不要解压**。
2. 打开 Claude 桌面端 → **Customize** → **Plugins**
3. 在「个人插件」区点 **+** → 选择上传插件文件 → 选中那个 zip
4. 上传后**立即可用**，没有审核等待

### 三个容易搞错的地方

⚠️ **不要把 zip 拖进对话框，然后让 Claude「帮我安装这个」。**
对话里的附件只是那次对话的可读文件，Claude 没有安装插件的能力。这样做你会以为装好了，实际什么都没发生。**安装只能在 Customize → Plugins 里做。**

⚠️ **每台电脑都要装一次。**
自己上传的插件保存在本机，不跟账号同步。换一台电脑用 Claude，要把同一个 zip 重新上传一次。

⚠️ **要用 Cowork tab，不是 Chat tab。**
Chat tab 无法访问你的本地文件夹，这个插件需要读你的 Excel 或 DOCX。

## 二、更新

收到新版 zip 时，**直接按上面的步骤再上传一次**即可。

**不需要先删旧的** —— 同名插件会自动覆盖。

### 0.44.0 更新说明

- 插件、审核规则和指标版本已统一更新为 `0.44.0`。
- 更新后，旧版本留下的历史分析不能继续复用，需重新发起审核。
- 源 Excel 和已经导出的报告不会被修改或删除。

## 三、使用

1. 切到 **Cowork** tab
2. 挂上存放待审 `.xlsx` 或 `.docx` 的本地文件夹
3. 直接用中文提需求，不需要记任何命令。例如：

   - 「把这些 Excel 完整审核一遍，告诉我哪里要改」
   - 「第 1、3 章有几个 PC、几个 FC，价格对不对」
   - 「这些付费分支值不值，回报够不够」
   - 「帮我检查这些章节的英文有没有翻译腔」
   - 「分析并优化这些付费选项，给我一套商业化重构方案」
   - 「评审这份 DOCX 小说大纲，检查缺少哪些内容，以及故事线、感情线、章节结构和付费机会」

## 四、结果存在哪

**结论会直接出现在聊天里**，你不需要去翻文件。

有三类任务会额外保存正式报告：

- 「完整审核」：`chapters-reviews/<编号>/analysis/audit-report.md`，另有编辑摘要 docx。
- 「按 v1.7 做付费结构与商业化重构」：`chapters-reviews/<编号>/analysis/monetization-v1.7/monetization-rebuild-v1.7.md`。
- 「评审 DOCX 小说大纲」：`chapters-reviews/<源文件名>-outline-review/`，根层只放 Markdown 评审报告。报告中的每个问题都写成“第几章＋Scene/选择节点＋可搜索原文”，你可以直接复制英文短句到 Word/WPS 搜索。插件使用的 JSON、JS 和其他工作文件统一放在其中的 `working-files/` 子目录，不会与报告混在一起。

它们互相独立：完整审核仍按当前项目规则执行，不会自动加入 v1.7 重构；v1.7 报告也不会改变完整审核的结论。

`working-files/` 子目录里还有插件自己用的 JSON、JS 和其他中间文件。**那些是给插件看的，你不用管。** 正常审核不会生成定位版 DOCX、PDF 或 PNG。报告的位置栏直接保留英文原文短引；在 Word/WPS 中搜索这句原文，就能回到对应章节和选择节点。

**你的源 Excel 和 DOCX 永远不会被修改**，插件只读不写。

## 五、要等多久

一次指标检查大约**几分钟**。

慢是因为插件不靠猜：它会真的去读章节正文，判断哪些选择组是捏脸流程、哪些是真正的选择点，然后才给出最终数字。第一次对一批文件提问最慢，之后再问同一批会快一些。

## 六、常见情况

**提示 Excel 格式有问题**
插件会给出具体的文件、Sheet、行号或单元格，以及怎么改。按提示修好 Excel 后重新提问即可。插件不会替你改 Excel。

**有几条写着「无法判断，需要你确认」**
最常见的原因是：插件无法确认你这次给的是不是完整的一本（比如只放了 1–5 章）。这是**正常的保守做法，不是出错** —— 涉及全书范围的规则（比如价格 30 的唯一性、全书 PO 上限）在证据不够时不会硬下结论。

每一条这样的项后面都会写清楚缺什么。如果那确实是完整的一本，回一句「这是完整的一本，一共 N 章」，插件会把这几条重新判断一遍。

**插件像是没生效**
确认三件事：这台电脑上装过、当前在 Cowork tab、文件夹已经挂上。

## 七、遇到问题时请提供

反馈问题时，把这三样一起给到：你提的原话、插件的回复、以及回复或报告末尾那行「插件版本 x.y.z」。版本号能确认你手上装的是不是最新版。
