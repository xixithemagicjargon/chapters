# 制作、检查与交付

## 每章制作顺序

1. 读取已确认pitch、上一章尾部、人物与购买状态。确定本章核心欲望、开场状态、必要变化与结尾未解答案。
2. 按choice-design完成PC/FC商品卡，避免与前章相同动机重复收费。定出全免费骨干、付费附加体验、L2与PO的位置。
3. 用chapter-plan-template梳理场景、价值变化与情绪曲线，给主线/各分支分配行预算，汇总应在500–600范围。预算只是预估，完成后实算。
4. 按场景写完整分支，之后通读完整免费路径和高价路径。先让每笔体验成立，再压缩语言。不要先填满500条空泛句子再插按钮。
5. 写入树结构JSON，检查并导出XLSX。选择按钮/正文保持同色；子分支及合流映射清晰。制作说明不进入Script列。
6. 回写项目状态中的已交章节、确认版本、情绪债、关系与资产变化、未来回调。批次交付时另查5章之间的接续和动机升级。

## 可运行工具

使用环境提供的Python 3（检查器仅需标准库），路径占位符由当前项目真实路径替换：

```bash
python3 scripts/check_chapter.py chapter-01.json --out work/ch01-checked.json
```

正式章任何硬错误返回非零并禁止正式导出。短片段调试可加`--fragment`：跳过500–600和最低回报长度的完整章要求，但仍检查语法、枚举、免费出口和价格等；输出明确标为fragment，不能称正式章通过。

导出依赖`@oai/artifact-tool`。通过工作区依赖工具获取Node和node_modules，设置专用环境变量`CHAPTERS_NODE_MODULES`为该node_modules绝对路径。没有可用依赖时保留JSON及检查结果，使用可用的表格技能完成输出，不把缺少的XLSX说成已生成。

```bash
node scripts/export_workbook.mjs work/ch01-checked.json outputs/chapter-01.xlsx work/ch01-preview
```

调用创建/编辑表格技能时遵守其依赖与开始记录约定。导出器提供五列稿、Choice Map以及每页范围预览。打开预览检查清晰度、换行、色块、表头和价格映射，正式章检查首部、关键分支/合流及末尾；有截断就修复后重导。用户要求DOCX时调用可用文档技能，保留同五列及分支底色，渲染逐页检查。不要只在聊天贴Markdown表代替要求的文件。

## 自动检查范围

- 数据结构、唯一ID、chapter范围、非空文本、Emotion/Thought Bubble、允许Text Type。
- 全部展开行500–600；所有显示文本120字符上限，对白>90提醒；换行及替换占位符提醒。
- FC全免费，PC/PO至少一个付费和恰好一个免费；普通价格10/12/17、排序及17/0、17/12/0、17/12/10/0阶梯。22/30或特殊价格需项目另设并人工判断，当前工具不自动放行。
- 选择必须有非空正文；正式稿付费分支最短正文≥10行，根级叙事L1≥100英文词；独立FC分支≥3行。词数以英语词口径计算，不与字符数混淆。
- 全部物理组数、叙事L1、含PO的L1、L2、PO、FC、付费按钮数；最短/最长路线、全免费路线区间及最大可达钻耗。
- 检查器不把未知key悄悄丢掉：不支持的条件/循环节点须另做引擎实现。

## 人工检查范围

以下不由通过收据证明：

- 原作阅读是否足够，成绩是否真实，核心情绪与pitch是否已确认。
- 铺垫是否真正点燃欲望，PC是否过早，8/10行铺垫、PC前三行OS、首PC前75行和FC间隔等项目规范是否逐项满足。
- 角色动机、英文自然度、三档价值、反击/亲密的合理性，3种回报是否真实不同。
- 每条免费/付费路线的事实是否在合流兼容；条件变量、道具/服装/秘密、称呼、时间与位置的跨章一致性。
- 子购买是否截断父购买的承诺，同一权益是否重复扣费；内容缺失是否被最长路径掩盖。
- 全书/批次PC密度、PO分布、早期亲密比例、总商业曲线与新书实际表现。
- 原生ML完整模板、后台ID、美术、声音、条件回调与导入引擎兼容性。

正式交付把以上必要检查写进简短QA记录，准确分为已查/待制作/无法验证；不要把“格式通过”改称“可直接上线”。单章用户仅需看到影响使用的事项，不展开工具日志。

## 有代表性的行为测试

维护技能时至少检查：仅给小说不会越过情绪确认直接写正文；只有情绪确认不会擅自当pitch通过；已授权制作一章不会每步重复求批；39.7%不会变每章配额；子收费退出保留父回报；三档付费不会吞掉免费项；有权威来源也不会把Episode价格套到Chapters；源文件和旧技能不被覆盖。
