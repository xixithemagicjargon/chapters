# PC、FC与PO设计

## 先区分对象

- FC是整个免费选择组；PC中的0钻退出只是一条免费分支，不能再算一个FC。
- 一级PC是不用先购买即可看见的收费组；二级PC是付费分支中真实可达的新收费组。付费分支中的免费子选择不等于二级PC。
- PO为付费服装，角色创建与捏脸另列。统计时同时给“叙事L1”和“L1含独立PO”，避免不同标准混算。
- 物理组是文档中的位置，逻辑PC是同一商品，曝光是玩家实际看见次数，付费按钮是组内选项，购买是一次交易。四者绝不混称。

## 先造机会，再写按钮

候选PC必须回答：当下想要什么、阻碍是什么、谁的行动创造机会、为何符合双方动机、玩家按下去能得到哪个明确变化。机会未成熟就先用FC/主线建立，不强行收费。

使用七步商品卡：

1. **核心欲望**：本笔推进全书哪一项期待，突破哪一道障碍？
2. **当前关系依据**：谁已经信任/知道/承诺什么；亲密为何合理；哪里仍会犹豫？
3. **选择前铺垫**：约10条有功能的行动、对白与内心，让玩家预见回报。不是复制十句“我很想”。在选择者最后三行中安排至少一句OS；popup按项目格式使用，不以广告话术代替剧情。
4. **按钮**：MC能执行的动作 + 可预期结果，英语约8–12词为编辑参考；声音自然更重要。不要写“提升亲密度/解锁精彩内容”。
5. **正文兑现**：前2–3行开始给回报，随后用动作、即时回应、关系/信息变化给出至少3种不同收获。至少10条有效正文，15–20条常更充分；不能用同义重复凑数。L1若按共享审核还需至少100英文词。
6. **退出与合流**：不买时女主为何这样选择，正常目标如何继续；合流哪些事实所有路线都成立？
7. **记住购买**：称呼、礼物、秘密、反馈或后文callback。没有引擎实现的回调标为制作待实现，不能谎称已生效。

信息类回报采用“更早/更深入/更私密地参与 + 对方反应 + 可选优势”；解决主线所需的唯一线索必须仍有免费获得路径。

## 档位差异

默认写作稿使用17/12/0，或确有完整单一商品时17/0；此默认为本技能在用户现有枚举下的工作选择，不是平台只有这两种结构。

用户选用三档商业化设计时先列17/12/10三种完整方案；若三档都要进同一游戏菜单，必须使用四按钮结构，并同步扩充Text Type和导入映射。不能把三档付费挤进三个按钮而删除免费项。

价格排序依据本书核心渴望的实现程度、主动性、关系后果、公开范围和独特反馈，不以露骨程度或字数排序。例如反击场景：17钻当众用证据让指控者撤回指控并承认你的功劳；12钻私下争取关键证人的支持并拿回机会；10钻若采用，则提供独立而完整的策略准备/专属线索体验。免费项可保存证据、选择稍后正式回应。各档都需真实铺垫，不能凭空改写人物能力。

同一购买若承诺“公开支持”，就必须兑现公开支持，不能只给私下安慰。高档不能比低档更迟、更弱；低档不故意失败。

## 二级PC与连续购买

L1先完整兑现。L2只能由新欲望、新反馈或关系变化触发，给出独立体验；拒绝L2也保留已买L1的完整回报。不要把“靠近、开始、完成”拆成三次收费。

高唤醒连续链是商业设计特例，不应被根级PC间的FC规则机械切碎，但必须有新的决定点和自然节奏。根级独立PC仍留互动空间。互斥分支重复出现同一权益，记录统一逻辑商品ID，实际扣费复用需引擎确认。

## FC如何让玩家玩起来

独立FC默认三个平等、不同的可行态度，如直接质问/机智试探/坦诚表达，不能全是同一句话的语气词。各分支至少3条反应与反馈作为工作基线；在合流时保留玩家表达的性格，必要时回收。

FC可以改变当前策略、谁先知道、谁主动、关系语气、局部后果；无需让20章主干彻底分裂。必要状态记录下来后，后续差异可由短回调体现。全免费路径也应有能力、欲望、关键信息和可信结局。

## PO

先有场合、观众和女主动机，再展示服装。价值可以是身份、私人偏好、功能、仪式意义或特别反馈，不能只写“更漂亮”。在资源表描述档位可见差异；没有素材ID时留待美术确认，不编造现成资源。买过的衣服和当众评价不能在免费路线无条件出现。

## 内容类型与时间

用双轴记录：**内容分类**（恋爱R、人格P、信息I、能力C；PO另列）和**购买动机**（亲密升级、态度、秘密、反击、修复、陪伴、造型、公开偏爱、能力高光）。两套体系不是一一对应，不把恋爱亲密等级与L1/L2付费深度混淆。

用户给出的五样本启发式：亲密39.7%、态度18.1%、秘密10.5%、反击7.9%、修复7.3%、其余16.5%。原报告总数为1,057个含付费分支的物理组；这些比例仅用于观察付费组内部构成，未在本次逐组重新打标核算，不等于PC/(PC+FC+PO)，不是新书配额。

前段先建立欲望和付费信任，中段增加关系与秘密价值，后段在危机之后兑现反击、公开选择、和解与亲密。题材和人物证据可改变顺序。相邻商品若重复同一幻想，必须增加新风险、新主动权、新关系阶段或回收；否则合并或替换。

## 实证迭代

将“这个PC会吸引人”写成可检验假设。分开跟踪到达曝光、点击购买、选择后退出、章间留存、复购与钻耗；明确每个指标分母、时间窗和付费/赠送钻构成。高购买率与高流失可同时存在。没有可比数据不说某桥段导致爆款；先改最可能的铺垫、承诺或兑现问题，再对比同口径样本。
