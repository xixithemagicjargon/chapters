# 情绪、关系与20章结构

## 从理论到可写的场景

- **Gwen Hayes / Romancing the Beat**：双主角都需要从防御走向能给予和接受爱的变化。四阶段用于检查相遇与绑定、靠近、退缩、争取与修复；20个节拍不等于20个游戏章节。
- **Pamela Regis / A Natural History of the Romance Novel**：社会环境、相遇、吸引、障碍、仿佛不可能结合的低谷、认知改变、表白、结合构成爱情叙事的诊断维度。重点审查障碍如何被人物克服，而非只问有没有婚礼。
- **Janice Radway / Reading the Romance**：特定读者群的阅读活动可提供私人时间和情绪补给。用于提出“被准确看见、被照顾、获得选择空间”的体验假设；不能外推为所有当代女性玩家的心理结论。
- **Tania Modleski / Loving with a Vengeance**：大众幻想可以同时承载欲望、愤怒和矛盾。允许玩家又想靠近又想保持权力；不要把支配幻想简单解释成玩家现实中愿意受压迫。
- **用户提供的麦基复习手册**：欲望 → 行动 → 现实与预期出现鸿沟 → 更难的选择 → 价值变化。采用其场景卡方法，不把手册的转述当作原书逐字引文。

出处与阅读范围见 [sources.md](sources.md)。这些是写作工具与研究视角，不是收入公式。

## 双主角关系引擎

每人写：旧伤、错误信念、保护策略、短期好处、长期代价、对方触发自己的方式、终局必须学会的新行动。再把二人的防御连成循环：A想靠近的方法为何使B退缩，B的退缩如何坐实A的恐惧。

至少给出几次与旧信念相反的实际体验：尊重能力、保密而不索取、共同快乐、允许拒绝、公开承担代价。欲望可以早出现，信任和承诺需要故事证据；不要把早期身体吸引写成未经建立的终身示爱。

## 四个batch的建议功能

| 范围 | 外部与关系任务 | 玩家主要期待 | 商业机会 |
| --- | --- | --- | --- |
| Ch1–5 | 迅速建立不公/欲望与吸引，明确走不开的理由，第一次破例 | “让我进入这个世界，让他真正看见我” | 具体体验、能力/态度、陪伴、轻度暧昧，有场合理由的PO |
| Ch6–10 | 用合作与冲突制造相爱证据，兑现阶段胜利，中点抬高失去的代价 | “这次靠近是真的，我们有可能” | 私人时刻、秘密的深入参与、关系升级、特殊反馈 |
| Ch11–15 | 既有秘密与防御产生实际后果，信任/公开关系受考验 | “他会怎样选择，我是否要继续信任” | 反击、公开维护、关键坦白、与动机相符的高强度回报 |
| Ch16–20 | 识别根因，用有代价的行动修复，高潮回收情绪债与主线 | “亲眼看见改变，亲手取得承诺的结局” | 共同反击、公开选择、修复与仪式、终局专属余韵 |

这是可移动的工作假设。快节奏、先婚后爱、复仇或多LI故事可重排，但仍须写明人物因果。不能为到Ch15而强行分手，也不能把所有奖励押到后五章。

## 每章先定情绪任务

写四句话：本章玩家最想要什么；谁怎样阻挡；女主作什么选择让局势变化；章末为什么必须继续。然后设计PC/FC，再回到场景顺序中调整铺垫与回报。

每个情节点记录：

| 项目 | 必须具体到 |
| --- | --- |
| 进入状态 | 已知信息、信任、权力、关系公开程度、当前渴望 |
| 触发 | 谁做了什么、为何现在做 |
| 价值变化 | 如“被怀疑→证明能力”“有选择→被迫表态”，不是单写“紧张→更紧张” |
| 情绪曲线 | 预期情绪名称 + 强度0–5 + 正负倾向；这是作者假设，不是测量数据 |
| 玩家动作 | FC如何塑造态度，PC额外满足什么，或这段为何无需选择 |
| 反馈 | 别人或环境如何实际回应 |
| 下一拍原因 | 本拍造成的新问题/机会 |

整章同时看外部价值变化和关系变化。情绪应有对比与喘息，不能靠连续羞辱或连续高热保持同一个音量。简短的日常和笑点若能改变信任或制造期待就有用；没有变化的转场合并。

## 钩子的停止位置

先写“玩家此刻最想知道的答案”，再找让答案改变关系/身份/命运的动作，把结尾放在动作完成前或后果尚未揭晓处。

- 身份即将公开：证据到了正确的人手里，尚未看到反应。
- 不可逆决定：女主作出选择，代价即将启动。
- 关系已被证明，危险同时启动：刚得到想要的偏爱，却有人看见。
- 局部胜利暴露更深真相：眼前敌人败了，但关键证据指向亲近的人。

下一章先承接真实后果，不以梦境/误听反复撤销钩子。付费场景的承诺先在本笔购买内兑现，不能把已经收钱的主要回报剪掉当章尾悬念。Ch20先解决核心情绪债，用户要求的末尾期待可落在幸福生活的新一步，而非推迟主线结局。
